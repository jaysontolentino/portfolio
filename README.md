## What I do

I care equally about what people click and what keeps it running. On the front end that means clean component architecture and interfaces that feel fast and intentional; on the back end it means well-modeled APIs and data. Across both, I follow consistent coding standards, clean architecture, and proven design patterns so what I build stays:

- 🧩 **Maintainable** — readable, well-organized code that the next person (or future me) can safely change
- 📈 **Scalable** — architecture that holds up as features, traffic, and teams grow
- 🔒 **Secure** — built with sound security practices from the start, not bolted on after
